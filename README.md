# Two Player Games

A cooperative parkour and puzzle game developed in Unreal Engine 5.

## About the Game

As multiplayer is a complex topic, I am initially developing a single-player demo to showcase the core gameplay mechanics.

The goal is to gather feedback through playtesting, identify bugs and polish the core mechanics before moving on to multiplayer.

The planned multiplayer experience will feature two players chained together, working cooperatively to overcome parkour challenges and solve puzzles.

## Current Development Status

The current release consists of a single demo level showcasing the game's movement mechanics and environment.

The project is still under development. Feedback and bug reports are welcome through GitHub Issues.

## Controls

| Key | Action |
|---|---|
| WASD | Movement |
| Space | Jump, Parkour Action, Ledge Hop while climbing |
| Left Control | Slide while sprinting |
| Left Shift | Sprint (Hold) |
| Jump towards a wall while sprinting | Wallrun |
| Q | Reset Character at Respawn Point |
| Esc | Pause Menu |

- Unreal Engine 5
