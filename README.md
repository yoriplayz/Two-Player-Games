# Two Player Games

**A cooperative parkour and puzzle-platforming experience where teamwork is the key to survival.**

Two Player Games is an Unreal Engine project built around an unusual concept: two players are physically connected by a chain, forcing them to coordinate their movements, overcome obstacles, and solve challenges together.

The project is currently under development. The available build is a single-player demo, with multiplayer functionality planned for a future release.

---

## 🎮 About the Game

Imagine navigating a challenging obstacle course — but you aren't entirely in control of your own movement.

In Two Player Games, players are connected by a chain. Every jump, movement, and decision affects both players. Success depends not only on individual skill, but also on coordination and teamwork.

### Planned Features
- **Cooperative Gameplay:** Work together to navigate challenging environments.
- **Chain-Based Movement:** Stay connected while managing the limitations of the chain.
- **Parkour Mechanics:** Jump, climb, and navigate obstacles.
- **Puzzle-Based Challenges:** Solve environmental challenges through coordination.
- **Multiplayer Support:** Designed with two-player gameplay in mind.

## Controls

| Key | Action |
|---|---|
| WASD | Movement |
| Space | Jump, Parkour Action, Ledge Hop while climbing |
| Left Control | Slide while sprinting |
| Left Shift | Sprint (Hold) |
| Jump towards a wall while sprinting | Wallrun |
| Q | Reset Character at Respawn Point |
| Esc | Pause Menu |

## 🚀 Getting Started

### Requirements
- Unreal Engine 5 (use the version specified by the project)
- Git
- Git LFS

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Two-Player-Games.git
   ```

2. Ensure Git LFS is installed:

   ```bash
   git lfs install
   git lfs pull
   ```

3. Open the `.uproject` file in Unreal Engine.
4. Allow Unreal Engine to initialise the project and compile any required modules.

**Note:** If the project uses third-party plugins, install or enable the required plugins before opening it.
